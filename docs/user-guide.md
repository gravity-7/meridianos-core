# MeridianOS Multi-Tenant Platform User Guide

Welcome to the Multi-Tenant Platform for MeridianOS!

## Managing Projects
Projects represent isolated AIOS environments.
1. Click **Create Project** in the Dashboard.
2. Select a **Template** (e.g., SaaS Web App, Mobile App).
3. The platform will provision the workspace, set up the agents, and start the project automatically.

## Team Collaboration
You can invite users to your projects:
1. Go to the **Team** tab.
2. Click **Invite Member**, enter their email, and select a Role (admin, operator, viewer).
3. Members can collaborate through Task Comments and Activity Feeds.

## Compliance and Reporting
Enterprise users can generate audit reports:
1. Navigate to the **Compliance** panel.
2. Select the report type (SOC2, GDPR, Cost Allocation, Model Usage).
3. Export as CSV or JSON to provide to your auditors.
