# Changelog

## [0.4.0] - Multi-Tenant Platform Release

### Added
- **Project Isolation:** Run multiple AIOS instances safely via `ProjectManager`.
- **Authentication:** JWT, API Keys, and OIDC Single Sign-On (GitHub, Google, Azure).
- **Billing:** Stripe integration for usage-based billing and license key generation.
- **Compliance:** SOC2, GDPR, Cost Allocation, and Model Usage reports.
- **Templates:** Rapidly bootstrap with predefined agent setups.
- **Kubernetes Support:** Helm charts with HPA, Persistent Volumes, and TLS.
- **Team Features:** Member invitations, role-based access, and task comments.
