# UXF-006 Contracts

## `GET /api/operations/search`

The route is additive to the existing operations API and is protected by the dashboard authorization and server-derived operational scope.

### Query

- `q`: required, trimmed UTF-8 text, 1–80 characters; raw query is never persisted in telemetry.
- `limit`: optional integer, default 20, maximum 50.
- Existing scope parameters (`tenant`, `project`, `provider`, `from`, `to`, `timezone`) are parsed by the existing operational scope boundary. Client tenant values cannot widen the authenticated scope.

### Success

```json
{
  "ok": true,
  "data": {
    "queryLength": 4,
    "results": [
      {
        "kind": "task",
        "id": "project/task-1",
        "label": "task-1",
        "description": "Task title",
        "href": "/app/operations/tasks/project%2Ftask-1?project=project",
        "scope": { "projectId": "project" },
        "command": null
      }
    ]
  },
  "scope": {},
  "meta": { "freshAsOf": "...", "correlationId": "..." }
}
```

Only safe metadata is returned. Empty results are valid. The server filters route visibility, task/run scope, provider names, and commands before serialization.

### Errors

- `400 SEARCH_QUERY_INVALID` for missing, overlong, or malformed query.
- `403 OPERATIONS_FORBIDDEN` when dashboard authorization or same-origin requirements fail.
- `429 RATE_LIMIT_EXCEEDED` under the existing API limiter.
- `500 OPERATIONS_UNAVAILABLE` with a generic message and correlation ID.

Errors do not reveal whether an out-of-scope entity exists.

## UX telemetry boundary

`recordUxfEvent(db, event)` accepts only the allowlisted fields in [data-model.md](../data-model.md). It is a no-op when telemetry is disabled and never throws into the product path. Unknown or secret-shaped fields are discarded before local persistence.

## Cloud compatibility

Existing `/api/cloud/auth/login`, `/api/cloud/machines`, `/api/cloud/health`, and `/api/cloud/policy` paths remain unchanged. Policy preview is client-side presentation of the submitted safe path/value metadata until a separately approved additive cloud preview contract exists; the existing mutation is not sent before explicit confirmation.
